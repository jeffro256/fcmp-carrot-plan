# FCMP++/Carrot Plan

## Intro

The `fcmp++-carrot.planner` file can be opened by the GNOME [Planner app](https://wiki.gnome.org/Apps(2f)Planner.html).
It describes remaining tasks involved with the research, development, and release of the FCMP++/Carrot hardfork of
Monero. For berevity, It does not include tasks completed before July 22nd, 2026, which is quite a lot.
